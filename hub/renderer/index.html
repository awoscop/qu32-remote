A show remembers which inputs each musician gets, their starting levels and limits. Musicians keep the same QR code when you open another show, and their phones update live.

Mix designer: which inputs each musician hears

Tick an input to put it in that musician's personal mix. Each musician can then raise or lower only those inputs on their phone, up to the limit you set under their card. Inputs are read from the same-numbered USB channel (set the desk's USB send to pre-fader direct out so your own fader moves never change their mix).

Talkback

Hold the button (or the space bar). Release to stop. Never stays on longer than 60 seconds.

Talk to one monitor with the button on its card, or to several with the buttons above. Two ways to supply your voice: desk microphone (plug a mic into the channel chosen here, leave the PC microphone "Not set" under Audio) or PC microphone (choose a mic and the Qu-32 USB return under Audio).

One-time desk setup for talkback
  1. Pick a spare input channel (default CH 32). Desk microphone: plug the mic into that channel's preamp. PC microphone: set its input source to USB and its USB channel to the same number as "USB return channel" above.
  2. Unmute it, fader at 0 dB, and switch off its LR assignment so talkback never reaches the main mix.
  3. Leave its sends at minus infinity. This app raises them only to the selected mixes while you hold the button, and sets them back to minus infinity on release.
  4. Do not use that channel for anything else: release always resets all of its monitor sends.
